# GhidraScrypt

*[Read in English](README.md)*

Скрипт для Ghidra на Python (Jython), который автоматизирует расшифровку XOR-обфусцированных строк в бинарнике прямо во время анализа малвари: находит строку, расшифровывает, декодирует и оставляет аннотации (комментарии, метку, bookmark) на месте — без ручного копирования байт в отдельный скрипт.

## Возможности

- Расшифровка XOR с однобайтовым (`[0x5A]`) или многобайтовым (`[0xDE, 0xAD, 0xBE, 0xEF]`) ключом
- Автоподбор однобайтового ключа перебором всех 256 вариантов (по доле печатных ASCII-символов в результате)
- Декодирование результата как ASCII или UTF-16LE
- Аннотирование прямо в Listing: Plate-комментарий с деталями (ключ, кодировка, hex, текст), EOL-комментарий с расшифрованной строкой, уникальная метка на адресе, bookmark для быстрой навигации
- Безопасное чтение памяти — при ошибке на "плохом" адресе просто пропускает участок и печатает предупреждение вместо падения скрипта

## Установка

1. Скопировать `#_Ghidra_Python_Script_XOR_String_Deobfuscation_&_Annotator.py` в папку скриптов Ghidra (`Window → Script Manager → Script Directories`, или дефолтная `~/ghidra_scripts`).
2. Обновить список скриптов в Script Manager (иконка refresh), скрипт появится в категории `MalwareAnalysis.Deobfuscation`.

## Использование

Есть три режима — скрипт сам выбирает подходящий по порядку:

1. **Выделение в Listing.** Выделить мышкой один или несколько диапазонов байт в окне Listing и запустить скрипт — обработает каждое выделение.
2. **`TARGET_ADDRESSES` в коде.** Если ничего не выделено, скрипт берёт список адресов из настроек в начале файла:
   ```python
   TARGET_ADDRESSES = [
       (0x00401050, 32),
       (0x00401090, 16),
   ]
   ```
3. **Интерактивный ввод.** Если и выделения, и `TARGET_ADDRESSES` пустые — скрипт спросит адрес и длину через диалоговое окно.

### Настройки (в начале файла)

| Параметр | Описание |
|---|---|
| `XOR_KEY` | Ключ XOR как список байт, например `[0x5A]` или `[0xDE, 0xAD, 0xBE, 0xEF]`. Игнорируется, если включён `AUTO_DETECT_KEY`. Если оставить пустым (`[]`) и автоподбор выключен — скрипт спросит ключ в диалоге. |
| `AUTO_DETECT_KEY` | `True`/`False`. Перебор всех 256 однобайтовых ключей и выбор по максимальной доле печатных символов. Работает только для однобайтового ключа. |
| `ENCODING` | `"ascii"` или `"utf16le"` — как декодировать расшифрованные байты. |
| `ADD_BOOKMARKS` | Создавать ли bookmark на найденной строке (видно в окне Bookmarks). |
| `TARGET_ADDRESSES` | Список `(адрес, длина_в_байтах)` для пакетной обработки без ручного выделения. |

## Пример вывода

```
[+] [0x00401050] -> https://example.com/gate.php
```

В Listing на этом адресе появится Plate-комментарий с ключом, hex-дампом и расшифрованным текстом, а также bookmark и метка `dec_https___...`.

## Ограничения

- Автоподбор ключа — эвристика по доле печатных ASCII-символов, на коротких буферах (меньше ~8 байт) может ошибаться — результат стоит проверять глазами.
- Автоподбор реализован только для однобайтового ключа.
